# اعتبارسنجی نسخه دریافت فقط از ترب

تاریخ: ۱۸ نوامبر ۲۰۲۶.

## اجراشده و موفق

- مجموعه بک‌اند: **۷۳ تست، ۷۳ موفق**؛ شامل منطق قبلی ثبت‌نام، امداد، حمل، پرداخت زرین‌پال و تست‌های بازار و دریافت ترب.
- استخراج JSON-LD و مشخصات __NEXT_DATA__ از نمونه پاک‌سازی‌شده HTML کاربر؛ تومان/ریال، نام و تصویر، پیشنهادهای فروشندگان و حذف پارامترهای session.
- جمع‌آوری لینک با مرورگر کنترل‌شده: یکتاسازی UUID، اسکرول، پایان واقعی، سقف ناقص و بسته‌شدن مرورگر در خطا.
- سازگاری مشترک یک قطعه با دو خودرو؛ رد تطبیق باتری صرفاً بر پایه آمپرساعت؛ رد مشخصات متناقض؛ حفظ سال، اتوماتیک، هیبرید و محدودیت موتور در داده منبع.
- ثبت پایدار محصول، یکتاسازی یک فروشنده، snapshot تکرارناپذیر و جست‌وجو بر مبنای رابطه سازگاری با داده کنترل‌شده.
- lint و TypeScript هر سه اپ مشتری، امدادگر و ادمین: موفق.
- Prisma validate: موفق. این بررسی جای اجرای migration روی PostgreSQL نیست.

## به‌روزرسانی تنظیمات بدون پنل ادمین

- ۷۹ تست بک‌اند موفق؛ شامل منابع env، حفظ cooldown پس از ری‌استارت، رد دسته نامعتبر، ادامه صف کارهای ردشده و جزئیات خطای HTTP مرورگر.
- lint و TypeScript اپ مشتری و امدادگر موفق؛ مسیر مستقل `/market` در هر دو پوشه اضافه شده است.
- اسکریپت فقط‌خواندنی `scripts/market-status.js` برای تعداد محصولات قابل نمایش، منابع، صف‌ها و cooldown اضافه شده است؛ اجرای واقعی آن روی PostgreSQL/Redis سرور هنوز انجام نشده است.
- پنل ادمین در این تغییر ویرایش نشده است. راهنمای فعلی: [استقرار بدون پنل ادمین](ENV-DEPLOYMENT.md).
- Docker در این محیط موجود نیست؛ build مسیرهای جدید، migration و تست مرورگر واقعی این نسخه اجرا نشده‌اند. تست‌های زنده زیر مربوط به نسخه قبل‌اند و به معنی رفع محدودیت فعلی سرور نیستند.

## آزمون زنده محدود

۱. Chrome موجود با Puppeteer، در حالت بدون پنجره و سقف پنج محصول، از دسته باتری ترب **۵ لینک یکتا** دریافت کرد. به علت سقف محصول، نتیجه complete=false بود؛ دریافت کامل دسته ادعا نشد.

۲. درخواست HTTP واقعی به محصول نمونه کاربر موفق بود: باتری اتمی صبا ۵۰ آمپر L1 قطب چپ، برند صبا، تصویر، کمترین قیمت ۴٬۱۰۰٬۰۰۰ تومان، بیشترین ۷٬۵۶۵٬۸۰۰ تومان و شش پیشنهاد استخراج شد. این ارقام فقط مشاهده زمان آزمون هستند و قیمت فعلی تضمین‌شده یا seed تولید نیستند.

۳. آزمون بعدی با سقف سه اسکرول، با SOURCE_ACCESS_DENIED متوقف شد. بنابراین پیمایش کامل دسته و دسترسی پایدار اثبات نشده‌اند. هیچ CAPTCHA حل یا محدودیتی با تعویض IP/هویت دور زده نشد.

مشخصات فنی و فهرست سازگاری __NEXT_DATA__ به‌طور مستقیم از HTML ارسالی کاربر بررسی و در fixture کوچک ذخیره شدند. JSON غیرمرتبط صفحه و رهگیری مرورگر وارد fixture نشده‌اند.

## آماده شده ولی اجرا نشده

- build تصاویر Docker بک‌اند و سه اپ.
- اجرای migration جدید و تست یکپارچه واقعی PostgreSQL/PostGIS/Redis.
- تست Playwright صفحه محصول و مدیریت لینک دستی ترب.
- پیمایش کامل دسته‌های بزرگ، آزمون بار و تضمین پوشش تمام خودروها و سازگاری‌های فنی.

Docker در این محیط موجود نیست. هیچ build محلی خارج از Docker اجرا نشده است. تست‌های دیتابیس و مرورگر برای معماری جدید به‌روز شده‌اند، اما وجود آن‌ها به معنی اجرای موفق نیست. دستورها و محدودیت‌ها در [README.md](README.md) آمده‌اند.

## اصلاح Scheduler و لوگو (۱۸ نوامبر)

- خروجی پنج فراخوانی advisory lock در bootstrap، ثبت محصول، پیگیری قیمت و پرداخت به متن تبدیل شد تا نوع void به Prisma تحویل نشود؛ رفتار قفل تراکنشی حفظ می‌شود.
- ۷۹ تست Node پس از تغییر موفق شدند. این تست‌ها جای آزمون واقعی پروتکل PostgreSQL نیستند؛ تست یکپارچه موجود bootstrap و ingest را روی دیتابیس واقعی پوشش می‌دهد، ولی به علت نبود Docker اینجا اجرا نشده است.
- صفحه مستقل /market در دو اپ طبق درخواست حذف شد؛ جمعه‌بازار داخل داشبورد /home باقی است. مدیریت منابع از env انجام می‌شود.
- فایل‌های PNG ارسالی بدون ویرایش تصویر وارد دو اپ شدند؛ لوگوی نوشتاری در رابط و نشان مربعی در manifest و آیکن مرورگر به کار می‌روند. کش Service Worker برای دریافت دارایی‌های جدید نسخه‌گذاری شد.
- رفع P2010 به معنی رفع SOURCE_ACCESS_DENIED یا حذف cooldown ترب نیست. داده‌های تولید بازنشانی نشده‌اند و schema تغییر نکرده است.
