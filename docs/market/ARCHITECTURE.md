# معماری دریافت ترب

تنها crawler فعال: لینک دستی browse ترب → صف torob-browse-v2 و Puppeteer → ذخیره UUID لینک‌ها → صف torob-product-v2 و HTTP → JSON-LD + __NEXT_DATA__ → کاتالوگ قطعه، فروشنده و سازگاری.

اسکرول و دریافت محصول وضعیت مستقل و پایدار دارند. قواعد سازگاری، ادعای منبع و تطبیق قطعی را جدا می‌کنند. سایر connectorها حذف شده‌اند؛ سوابق تاریخی و مالی قبلی حفظ می‌شوند. جزئیات و محدودیت‌ها در [README.md](README.md).
